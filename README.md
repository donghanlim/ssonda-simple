# 쏜다 심플 (ssonda-simple)

업체 계좌번호를 입력하면 QR이 생성되고, 손님이 QR을 찍으면 은행 선택 → 은행 앱 실행 + 계좌번호 자동 복사.
서버·DB·로그인 없는 정적 페이지입니다. 입력값은 QR/링크(#뒤 해시)에만 담기며 서버로 전송되지 않습니다.

## 배포 (GitHub Pages)
Settings → Pages → Deploy from a branch → main / (root)

## 한계
- 은행 앱 스킴·스토어 ID는 실기기 검증 전 값입니다. 앱 실행이 안 되면 스토어로 이동합니다.
- 앱에 계좌번호를 자동 입력하지는 못합니다(복사 후 붙여넣기).
- 토스·카카오뱅크 등은 송금 화면까지 직접 연결되지 않고 앱 홈이 열립니다.
